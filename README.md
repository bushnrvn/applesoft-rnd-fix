# applesoft-rnd-fix

An Applesoft BASIC patch that restores the entropy source of the RND(n) function as found in Wozniak's Integer BASIC.

Currently, patch_lc.bin is the only available version. This must be loaded via lc_loader.bin.

Requires an Apple II or II+ with a 16K language card installed in slot 0, or any Apple IIe, IIc, or IIc+. Apple IIgs compatibility is untested.
